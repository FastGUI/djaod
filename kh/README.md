## ✨ លក្ខណៈពិសេសសំខាន់ៗ

### 🚀 បច្ចេកវិទ្យាជំនាន់ថ្មី
ដំណើរការដោយ **ម៉ាស៊ីន async I/O មិនទប់ស្កាត់ + មូលដ្ឋានទិន្នន័យចែកចាយ** គ្រប់គ្រងបន្ទុកការងារផ្សេងគ្នាក្នុងពេលដំណាលគ្នាដោយងាយស្រួល។

### 🎹 ការរកឃើញ BPM និង KEY ដោយស្វ័យប្រវត្តិ
បញ្ចូលបទហើយទាញយកភ្លាមៗនូវ **BPM, KEY តន្ត្រី, អត្រាប៊ីត, ឆានែល, អត្រាគំរូ និងរូបភាពក្រប** — ទាំងអស់ក្នុងជំហានតែមួយ។

### ☁️ ការរក្សាទុកលើពពក និងការពន្លឿន CDN
ស្ថាបត្យកម្មបំបែក: ឡូជីកគេហទំព័រដំណើរការដោយឯករាជ្យ ខណៈឯកសារមេឌៀទាំងអស់រស់នៅក្នុងកន្លែងផ្ទុកវត្ថុពពកជាមួយ **ការពន្លឿន CDN សកល**។

### 🔒 ការផ្សាយ HLS ពហុអត្រាប៊ីត
ការបញ្ចូលមួយបង្កើតដោយស្វ័យប្រវត្តិនូវបំរែបំរួលអត្រាប៊ីត **320k / 256k / 192k / 128k**។ ការចាក់សាកល្បងប្រើ **M3U8 / HLS ការផ្សាយតាមលក្ខខណ្ឌ** ការពារការលួចសំឡេងតាមកម្មវិធីរុករក។

### 🛒 ប្រព័ន្ធពាណិជ្ជកម្មអេឡិចត្រូនិកពេញលេញ
ផលិតផលពហុបំរែបំរួល ការពិនិត្យអតិថិជន ការគ្រប់គ្រងស្តុក ការតាមដានការដឹកជញ្ជូន ការគាំទ្រច្រកទូទាត់ច្រើន។ លក់ **USB DJ ឧបករណ៍ សំបុត្រព្រឹត្តិការណ៍ គូប៉ុង និងធនធានឌីជីថល**។

### 🎤 វេទិកាសិល្បករ / អ្នកផលិត
ការដាក់ស្នើ → ការពិនិត្យឡើងវិញ → **ការបែងចែកប្រាក់ចំណូលដែលអាចកំណត់បាន** → ផ្ទាំងគ្រប់គ្រងប្រាក់ចំណូល → ការគ្រប់គ្រងការទូទាត់។

### 💬 សហគមន៍ និងសង្គម
បង្កើតឬចូលរួមក្រុម ប្រកាសបច្ចុប្បន្នភាព បញ្ចេញមតិ ចូលចិត្ត បង្ហោះឡើងវិញ និងចែករំលែក។

### 📢 ឧបករណ៍ទីផ្សារ
**ការលក់ពន្លឺ · ការទិញជាក្រុម · ការបញ្ជាទិញមុន · ពិន្ទុភក្តីភាព · កម្រិត VIP** — ឧបករណ៍ផ្សព្វផ្សាយសម្បូរបែបដើម្បីបង្កើនអត្រាបំប្លែងសមាជិក។

### 📺 មជ្ឈមណ្ឌលមាតិការួម
គ្រប់គ្រង **បទតន្ត្រី អាល់ប៊ុម បញ្ជីចាក់ វីដេអូ ពាណិជ្ជកម្មអេឡិចត្រូនិក សហគមន៍ និងការដាក់ស្នើសិល្បករ** ពីផ្ទាំងគ្រប់គ្រងតែមួយ។

## 🚀 ចាប់ផ្ដើររហ័ស

```sh
curl -sL https://download.djaod.com/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

- អ្នកចាប់ផ្តើមត្រូវបានណែនាំឱ្យប្រើ **BaoTa Panel** + ស្គ្រីបដំឡើងមួយចុច
- ដំឡើង `Nginx`, `Node.js` និង `Redis` តាមរយៈ BaoTa Panel ជាមុនសិន ប៉ុន្តែ **កុំដំឡើង `MongoDB` តាមរយៈ BaoTa Panel** — មិនអាចកំណត់រចនាសម្ព័ន្ធចង្កោមបានទេ (ប្រព័ន្ធត្រូវការ!)
- នៅពេលស្គ្រីបបញ្ចប់ដោយជោគជ័យ បង្កើតគេហទំព័រ Node.js នៅក្នុង BaoTa Panel
- បង្កើត **គេហទំព័រផ្នែកខាងមុខ** ជា `"Default Project"` កំណត់ចំណុចចូលជា `/index.js` ពាក្យបញ្ជាចាប់ផ្ដើមជា `npm run index` ច្រកជា `3080`
- បង្កើត **គេហទំព័រផ្នែកខាងក្រោយ** ជា `"Default Project"` កំណត់ចំណុចចូលជា `/admin.js` ពាក្យបញ្ជាចាប់ផ្ដើមជា `npm run admin` ច្រកជា `3000`
- ចំណាំ: BaoTa Panel ចាប់ផ្ដើមគេហទំព័រដោយស្វ័យប្រវត្តិបន្ទាប់ពីបង្កើត — បញ្ឈប់ពួកវាជាមុនសិន បន្ទាប់មកប្រើពាក្យបញ្ជាខាងក្រោម
- ចាប់ផ្ដើមគេហទំព័រផ្នែកខាងមុខ:
```sh
systemctl start djaod-index.service
```
- ចាប់ផ្ដើមគេហទំព័រផ្នែកខាងក្រោយ:
```sh
systemctl start djaod-admin.service
```
