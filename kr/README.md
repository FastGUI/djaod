## ✨ 주요 기능

### 🚀 차세대 기술 스택
**논블로킹 비동기 I/O 엔진 + 분산 데이터베이스**로 구동되어 높은 동시성 워크로드를 쉽게 처리합니다. 기존 CMS 플랫폼을 능가하며 수백 명의 DJ 사이트 운영자가 라이브러리, 주문, 회원을 동시에 관리할 수 있습니다.

### 🎹 자동 BPM & KEY 감지
트랙을 업로드하면 **BPM, 음악 KEY, 비트레이트, 채널, 샘플 레이트, 커버 아트**를 즉시 추출합니다 — 한 번에 모든 것을 처리합니다.

### ☁️ 클라우드 스토리지 & CDN 가속
분리된 아키텍처: 웹사이트 로직은 독립적으로 실행되고 모든 미디어 파일은 **글로벌 CDN 가속**을 통해 클라우드 오브젝트 스토리지에 저장됩니다.

### 🔒 멀티 비트레이트 HLS 스트리밍
한 번의 업로드로 자동으로 **320k / 256k / 192k / 128k** 비트레이트 변형을 생성합니다. 체험 재생에는 **M3U8 / HLS 적응형 스트리밍**을 사용하여 브라우저 기반 오디오 도용을 방지합니다.

### 🛒 완전한 전자상거래 스위트
다중 변형 제품, 고객 리뷰, 재고 관리, 배송 추적, 다중 결제 게이트웨이 지원. **DJ USB 드라이브, 장비, 이벤트 티켓, 쿠폰 및 디지털 리소스**를 판매할 수 있습니다.

### 🎤 아티스트 / 프로듀서 플랫폼
제출 → 검토 → **구성 가능한 수익 분배** → 수익 대시보드 → 지급 관리. 완전한 음악 생태계를 구축하세요.

### 💬 커뮤니티 & 소셜
서클을 만들거나 가입하고, 업데이트를 게시하고, 댓글을 달고, 좋아요를 누르고, 리포스트하고, 공유하세요. 참여와 유지율을 높이세요.

### 📢 마케팅 툴킷
**플래시 세일 · 공동 구매 · 사전 주문 · 로열티 포인트 · VIP 등급** — 회원 전환율을 높이고 수익을 극대화하는 풍부한 프로모션 도구입니다.

### 📺 통합 콘텐츠 허브
**음악 트랙, 앨범, 재생 목록, 비디오, 전자상거래, 커뮤니티, 아티스트 제출물**을 단일 대시보드에서 관리하세요.

## 🚀 빠른 시작

```sh
curl -sL https://download.djaod.com/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

- 초보자는 **BaoTa Panel** + 원클릭 설치 스크립트 사용을 권장합니다
- 먼저 BaoTa Panel에서 `Nginx`, `Node.js`, `Redis`를 설치하고, **`MongoDB`는 BaoTa Panel에서 설치하지 마세요** — 클러스터 구성을 할 수 없습니다 (시스템 요구사항!)
- 스크립트가 성공적으로 완료되면 BaoTa Panel에서 Node.js 사이트를 생성합니다
- **프론트엔드 사이트**를 `"Default Project"`로 생성, 진입점을 `/index.js`로, 시작 명령을 `npm run index`로, 포트를 `3080`으로 설정합니다
- **백엔드 사이트**를 `"Default Project"`로 생성, 진입점을 `/admin.js`로, 시작 명령을 `npm run admin`으로, 포트를 `3000`으로 설정합니다
- 참고: BaoTa Panel은 생성 후 자동으로 사이트를 시작합니다 — 먼저 중지한 후 아래 명령을 사용하세요
- 프론트엔드 사이트 시작:
```sh
systemctl start djaod-index.service
```
- 백엔드 사이트 시작:
```sh
systemctl start djaod-admin.service
```
