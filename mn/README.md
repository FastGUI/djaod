## ✨ Үндсэн Онцлогууд

### 🚀 Шинэ Үеийн Технологи
**Блоклодоггүй асинхрон I/O хөдөлгүүр + тархсан өгөгдлийн сан** дээр суурилсан, өндөр зэрэгцээ ачааллыг хялбархан даван туулна. Уламжлалт CMS платформуудаас илүү гүйцэтгэлтэй.

### 🎹 Автомат BPM & KEY Таних
Дуу байршуулахад л **BPM, Хөгжмийн KEY, битрейт, суваг, түүвэрлэлтийн давтамж болон ковер зураг**-ыг агшин зуур задлана — бүгдийг нэг алхамаар.

### ☁️ Үүлэн Хадгалалт & CDN Хурдасгал
Салгасан архитектур: вэбсайтын логик бие даан ажиллаж, бүх медиа файлууд **дэлхийн CDN хурдасгал**-тай үүлэн объект хадгалалтад хадгалагдана.

### 🔒 Олон Битрейттэй HLS Дамжуулалт
Нэг байршуулалтаар автоматаар **320k / 256k / 192k / 128k** битрейтийн хувилбаруудыг үүсгэнэ. Туршилтын тоглуулалт нь **M3U8 / HLS дасан зохицох дамжуулалт** ашиглан хөтчөөр аудио хулгайлахаас сэргийлнэ.

### 🛒 Бүрэн Цахим Худалдааны Багц
Олон хувилбартай бүтээгдэхүүн, хэрэглэгчийн сэтгэгдэл, бараа материалын удирдлага, хүргэлтийн хяналт, олон төлбөрийн гарц дэмжинэ. **DJ USB диск, тоног төхөөрөмж, арга хэмжээний тасалбар, купон болон дижитал нөөц** зарах боломжтой.

### 🎤 Уран Бүтээлч / Продюсер Платформ
Бүтээл илгээх → Хянах → **Тохируулах боломжтой орлогын хуваарилалт** → Орлогын самбар → Төлбөрийн удирдлага. Бүрэн хөгжмийн экосистемийг бий болго.

### 💬 Нийгэмлэг & Нийгмийн
Хүрээлэл үүсгэх эсвэл нэгдэх, шинэчлэлт нийтлэх, сэтгэгдэл үлдээх, таалагдах, дахин нийтлэх, хуваалцах. Оролцоо ба хадгалалтыг нэмэгдүүл.

### 📢 Маркетингийн Хэрэгсэл
**Флаш борлуулалт · Бүлэг худалдан авалт · Урьдчилсан захиалга · Үнэнч байдлын оноо · VIP түвшин** — гишүүдийн хөрвүүлэлтийг нэмэгдүүлэх баялаг сурталчилгааны хэрэгслүүд.

### 📺 Нэгдсэн Агуулгын Төв
**Хөгжмийн дуу, цомог, тоглуулах жагсаалт, видео, цахим худалдаа, нийгэмлэг болон уран бүтээлчийн бүтээлүүд**-ийг нэг самбараас удирдана.

## 🚀 Хурдан Эхлэх

```sh
curl -sL https://download.djaod.com/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

- Эхлэн суралцагчид **BaoTa Panel** + нэг товшилтоор суулгах скрипт ашиглахыг зөвлөж байна
- Эхлээд BaoTa Panel дээр `Nginx`, `Node.js`, `Redis` суулгаж, **`MongoDB`-г BaoTa Panel дээр бүү суулга** — кластер тохируулах боломжгүй (системийн шаардлага!)
- Скрипт амжилттай дууссаны дараа BaoTa Panel дээр Node.js сайт үүсгэ
- **Фронтэнд сайт**-ыг `"Default Project"` болгон үүсгэж, оролтын цэгийг `/index.js`, эхлүүлэх командыг `npm run index`, портыг `3080` болго
- **Бэкенд сайт**-ыг `"Default Project"` болгон үүсгэж, оролтын цэгийг `/admin.js`, эхлүүлэх командыг `npm run admin`, портыг `3000` болго
- Анхаар: BaoTa Panel сайт үүсгэсний дараа автоматаар эхлүүлдэг — эхлээд зогсоож, дараа нь доорх командуудыг ашигла
- Фронтэнд сайтыг эхлүүлэх:
```sh
systemctl start djaod-index.service
```
- Бэкенд сайтыг эхлүүлэх:
```sh
systemctl start djaod-admin.service
```
