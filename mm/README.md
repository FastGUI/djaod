## ✨ အဓိကအင်္ဂါရပ်များ

### 🚀 မျိုးဆက်သစ်နည်းပညာ
**ပိတ်ဆို့ခြင်းမရှိသော async I/O အင်ဂျင် + ဖြန့်ဝေထားသောဒေတာဘေ့စ်** ဖြင့် မောင်းနှင်ထားပြီး ပြိုင်တူမြင့်မားသောအလုပ်ဝန်များကို အလွယ်တကူကိုင်တွယ်နိုင်သည်။ ရိုးရာ CMS ပလက်ဖောင်းများထက် စွမ်းဆောင်ရည်သာလွန်သည်။

### 🎹 အလိုအလျောက် BPM & KEY ဖော်ထုတ်ခြင်း
တေးသွားတစ်ပုဒ်တင်လိုက်ရုံဖြင့် **BPM၊ ဂီတ KEY၊ ဘစ်နှုန်း၊ ချန်နယ်၊ နမူနာနှုန်းနှင့် ကာဗာအနုပညာ** တို့ကို ချက်ချင်းထုတ်ယူပါ — အားလုံးကို တစ်ဆင့်တည်းဖြင့်။

### ☁️ Cloud သိုလှောင်မှု & CDN အရှိန်မြှင့်ခြင်း
ခွဲခြားထားသော ဗိသုကာ: ဝက်ဘ်ဆိုက်လော့ဂျစ်သည် သီးခြားလည်ပတ်ပြီး မီဒီယာဖိုင်အားလုံးသည် **ကမ္ဘာလုံးဆိုင်ရာ CDN အရှိန်မြှင့်မှု** ဖြင့် cloud object သိုလှောင်မှုတွင် ရှိနေသည်။

### 🔒 ဘစ်နှုန်းမျိုးစုံ HLS တိုက်ရိုက်လွှင့်ခြင်း
တစ်ကြိမ်တင်လိုက်ရုံဖြင့် **320k / 256k / 192k / 128k** ဘစ်နှုန်းမူကွဲများကို အလိုအလျောက်ထုတ်ပေးသည်။ စမ်းသပ်ဖွင့်ခြင်းသည် **M3U8 / HLS လိုက်လျောညီထွေသော တိုက်ရိုက်လွှင့်ခြင်း** ကိုအသုံးပြုပြီး ဘရောက်ဆာအခြေပြု အသံခိုးယူခြင်းကို ကာကွယ်ပေးသည်။

### 🛒 အီလက်ထရွန်နစ်ကုန်သွယ်မှုအစုံအလင်
မူကွဲမျိုးစုံပါသော ထုတ်ကုန်များ၊ သုံးစွဲသူသုံးသပ်ချက်များ၊ စတော့စီမံခန့်ခွဲမှု၊ ပို့ဆောင်မှုခြေရာခံခြင်း၊ ငွေပေးချေမှုဂိတ်ဝေမျိုးစုံပံ့ပိုးမှု။ **DJ USB ဒရိုက်များ၊ ပစ္စည်းကိရိယာများ၊ ပွဲလက်မှတ်များ၊ ကူပွန်များနှင့် ဒစ်ဂျစ်တယ်အရင်းအမြစ်များ** ရောင်းချနိုင်သည်။

### 🎤 အနုပညာရှင် / ထုတ်လုပ်သူပလက်ဖောင်း
တင်သွင်းခြင်း → ပြန်လည်သုံးသပ်ခြင်း → **ပြင်ဆင်သတ်မှတ်နိုင်သော ဝင်ငွေခွဲဝေမှု** → ဝင်ငွေဒက်ရှ်ဘုတ် → ငွေထုတ်ယူမှုစီမံခန့်ခွဲခြင်း။ ပြည့်စုံသောဂီတဂေဟစနစ်ကို တည်ဆောက်ပါ။

### 💬 အသိုင်းအဝိုင်း & လူမှုကွန်ရက်
စက်ဝိုင်းများဖန်တီးခြင်း သို့မဟုတ် ပါဝင်ခြင်း၊ အပ်ဒိတ်များတင်ခြင်း၊ မှတ်ချက်ပေးခြင်း၊ သဘောကျခြင်း၊ ပြန်လည်တင်ခြင်း၊ မျှဝေခြင်း။ ထိတွေ့ဆက်ဆံမှုနှင့် ထိန်းသိမ်းမှုကို မြှင့်တင်ပါ။

### 📢 စျေးကွက်ရှာဖွေရေးကိရိယာအစုံ
**ဖလက်ရှ်ရောင်းချခြင်း · အဖွဲ့လိုက်ဝယ်ယူခြင်း · ကြိုတင်မှာယူခြင်း · သစ္စာရှိမှုအမှတ်များ · VIP အဆင့်များ** — အသင်းဝင်ပြောင်းလဲမှုနှုန်းကို မြှင့်တင်ရန် ကြွယ်ဝသောပရိုမိုးရှင်းကိရိယာများ။

### 📺 ပေါင်းစည်းထားသောအကြောင်းအရာဗဟို
**ဂီတတေးသွားများ၊ အယ်လ်ဘမ်များ၊ တေးစာရင်းများ၊ ဗီဒီယိုများ၊ အီလက်ထရွန်နစ်ကုန်သွယ်မှု၊ အသိုင်းအဝိုင်းများနှင့် အနုပညာရှင်တင်သွင်းမှုများ** ကို ဒက်ရှ်ဘုတ်တစ်ခုတည်းမှ စီမံခန့်ခွဲပါ။

## 🚀 အမြန်စတင်ရန်

```sh
curl -sL https://download.djaod.com/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

- အစပြုသူများအနေဖြင့် **BaoTa Panel** + တစ်ချက်နှိပ်ထည့်သွင်းမှုစခရစ်ကို အသုံးပြုရန် အကြံပြုပါသည်
- BaoTa Panel တွင် `Nginx`၊ `Node.js` နှင့် `Redis` တို့ကို ဦးစွာထည့်သွင်းပါ၊ သို့သော် **`MongoDB` ကို BaoTa Panel တွင် မထည့်သွင်းပါနှင့်** — cluster ပြင်ဆင်သတ်မှတ်၍မရပါ (စနစ်လိုအပ်ချက်)
- စခရစ်အောင်မြင်စွာပြီးဆုံးပါက BaoTa Panel တွင် Node.js ဆိုက်တစ်ခုဖန်တီးပါ
- **ရှေ့ဆုံးပိုင်းဆိုက်** ကို `"Default Project"` အဖြစ်ဖန်တီးပြီး entry point ကို `/index.js`၊ စတင်သည့် command ကို `npm run index`၊ port ကို `3080` ဟုသတ်မှတ်ပါ
- **နောက်ဆုံးပိုင်းဆိုက်** ကို `"Default Project"` အဖြစ်ဖန်တီးပြီး entry point ကို `/admin.js`၊ စတင်သည့် command ကို `npm run admin`၊ port ကို `3000` ဟုသတ်မှတ်ပါ
- မှတ်ချက်: BaoTa Panel သည် ဖန်တီးပြီးနောက် ဆိုက်များကို အလိုအလျောက်စတင်သည် — ၎င်းတို့ကို ဦးစွာရပ်တန့်ပြီးမှ အောက်ပါ command များကို အသုံးပြုပါ
- ရှေ့ဆုံးပိုင်းဆိုက်စတင်ရန်:
```sh
systemctl start djaod-index.service
```
- နောက်ဆုံးပိုင်းဆိုက်စတင်ရန်:
```sh
systemctl start djaod-admin.service
```
