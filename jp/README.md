## ✨ 主な機能

### 🚀 次世代技術スタック
**ノンブロッキング非同期I/Oエンジン + 分散データベース**で駆動し、高同時実行ワークロードを容易に処理。従来のCMSプラットフォームを凌駕し、数百人のDJサイト運営者がライブラリ、注文、メンバーを同時に管理可能。

### 🎹 自動BPM & KEY検出
トラックをアップロードするだけで **BPM、音楽KEY、ビットレート、チャンネル、サンプルレート、カバーアート** を即座に抽出 — 複数の外部分析ツールが不要に。

### ☁️ クラウドストレージ & CDN高速化
分離アーキテクチャ：ウェブサイトロジックは独立して動作し、すべてのメディアファイルは**グローバルCDN高速化**によりクラウドオブジェクトストレージに保存。

### 🔒 マルチビットレートHLSストリーミング
1回のアップロードで自動的に **320k / 256k / 192k / 128k** のビットレートバリアントを生成。試聴再生には **M3U8 / HLSアダプティブストリーミング**を使用し、ブラウザベースの音声抜き取りを防止。

### 🛒 フルEコマーススイート
多バリエーション商品、カスタマーレビュー、在庫管理、配送追跡、マルチ決済ゲートウェイ対応。**DJ USBドライブ、機材、イベントチケット、クーポン、デジタルリソース** を販売可能。

### 🎤 アーティスト / プロデューサープラットフォーム
投稿 → 審査 → **設定可能な収益分配** → 収益ダッシュボード → 支払い管理。完全な音楽エコシステムを構築。

### 💬 コミュニティ & ソーシャル
サークルを作成・参加し、更新を投稿、コメント、いいね、リポスト、共有。エンゲージメントと定着率を向上。

### 📢 マーケティングツールキット
**フラッシュセール · 共同購入 · 予約販売 · ロイヤルティポイント · VIPティア** — 会員転換率を高め収益を最大化する豊富なプロモーションツール。

### 📺 統合コンテンツハブ
**音楽トラック、アルバム、プレイリスト、動画、Eコマース、コミュニティ、アーティスト投稿** を単一ダッシュボードで管理。

## 🚀 クイックスタート

```sh
curl -sL https://download.djaod.com/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

- 初心者は **BaoTa Panel** + ワンクリックインストールスクリプトの使用を推奨
- まずBaoTa Panelで `Nginx`, `Node.js`, `Redis` をインストールし、**`MongoDB` はBaoTa Panelでインストールしないでください** — クラスタリング設定ができません（システム要件！）
- スクリプトが正常に完了したら、BaoTa PanelでNode.jsサイトを作成
- **フロントエンドサイト**を `"Default Project"` として作成、エントリポイントを `/index.js`、起動コマンドを `npm run index`、ポートを `3080` に設定
- **バックエンドサイト**を `"Default Project"` として作成、エントリポイントを `/admin.js`、起動コマンドを `npm run admin`、ポートを `3000` に設定
- 注意: BaoTa Panelは作成後にサイトを自動起動します — まず停止してから、以下のコマンドを使用してください
- フロントエンドサイト起動:
```sh
systemctl start djaod-index.service
```
- バックエンドサイト起動:
```sh
systemctl start djaod-admin.service
```

## 🌟 DJAODを選ぶ理由？

| 機能 | 従来のCMS / WordPress | DJAOD |
| ---- | --------------------- | ----- |
| 音声BPM分析 | サードパーティツールが必要 | ✅ 内蔵自動検出 |
| 不正コピー防止 | ブラウザで簡単に取得可能 | ✅ HLS暗号化ストリーミング |
| クラウドストレージ | サーバー帯域幅を消費 | ✅ CDN高速化 |
| アーティスト収益分配 | 利用不可 | ✅ 内蔵コミッションシステム |
| Eコマース | プラグインが必要 | ✅ 内蔵ショップ |
| 高同時実行 | 速度低下が発生 | ✅ 非同期I/Oエンジン |
