## ✨ Ключевые Возможности

### 🚀 Технологический Стек Нового Поколения
Работает на **неблокирующем асинхронном I/O движке + распределённой базе данных**, легко справляясь с высокими параллельными нагрузками. Превосходит традиционные CMS — поддерживает сотни DJ-администраторов, управляющих библиотеками, заказами и участниками одновременно с откликом менее секунды.

### 🎹 Автоматическое Определение BPM и Тональности
Загрузите трек и мгновенно извлеките **BPM, музыкальный KEY, битрейт, каналы, частоту дискретизации и обложку** — всё в один шаг. Больше не нужны многочисленные внешние инструменты анализа.

### ☁️ Облачное Хранение и CDN-Ускорение
Разделённая архитектура: логика сайта работает независимо, а все медиафайлы хранятся в облачном объектном хранилище с **глобальным CDN-ускорением**.

### 🔒 Многобитрейтный HLS-Стриминг
Одна загрузка автоматически генерирует варианты с битрейтом **320k / 256k / 192k / 128k**. Пробное воспроизведение использует **M3U8 / HLS адаптивный стриминг**, предотвращая кражу аудио через браузер.

### 🛒 Полный Комплект Электронной Коммерции
Многовариантные товары, отзывы клиентов, управление запасами, отслеживание доставки, поддержка нескольких платёжных шлюзов. Продавайте **DJ USB-накопители, оборудование, билеты на мероприятия, купоны и цифровые ресурсы**.

### 🎤 Платформа для Артистов / Продюсеров
Загрузка → Проверка → **Настраиваемое распределение дохода** → Панель доходов → Управление выплатами. Создайте полноценную музыкальную экосистему.

### 💬 Сообщество и Социальные Функции
Создавайте круги или присоединяйтесь к ним, публикуйте обновления, комментируйте, ставьте лайки, делайте репосты и делитесь. Повышайте вовлечённость и удержание.

### 📢 Маркетинговый Инструментарий
**Флэш-распродажи · Групповые покупки · Предзаказы · Бонусные баллы · VIP-уровни** — богатые инструменты продвижения для повышения конверсии участников.

### 📺 Единый Контент-Хаб
Управляйте **музыкальными треками, альбомами, плейлистами, видео, электронной коммерцией, сообществами и загрузками артистов** из единой панели управления.

## 🚀 Быстрый Старт

```sh
curl -sL https://download.djaod.com/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

- Новичкам рекомендуется использовать **BaoTa Panel** + скрипт установки в один клик
- Сначала установите `Nginx`, `Node.js` и `Redis` через BaoTa Panel, но **не устанавливайте `MongoDB` через BaoTa Panel** — невозможно настроить кластеризацию (требование системы!)
- После успешного выполнения скрипта создайте сайт Node.js в BaoTa Panel
- Создайте **фронтенд-сайт** как `"Default Project"`, установите точку входа `/index.js`, команду запуска `npm run index`, порт `3080`
- Создайте **бэкенд-сайт** как `"Default Project"`, установите точку входа `/admin.js`, команду запуска `npm run admin`, порт `3000`
- Примечание: BaoTa Panel автоматически запускает сайты после создания — сначала остановите их, затем используйте команды ниже
- Запуск фронтенд-сайта:
```sh
systemctl start djaod-index.service
```
- Запуск бэкенд-сайта:
```sh
systemctl start djaod-admin.service
```
