## ✨ ฟีเจอร์หลัก

### 🚀 เทคโนโลยีล่าสุด
ขับเคลื่อนด้วย **non-blocking async I/O engine + ฐานข้อมูลแบบกระจาย** รองรับการทำงานพร้อมกันสูง ประสิทธิภาพเหนือกว่า CMS ทั่วไป รองรับผู้ดูแลเว็บดีเจหลายร้อยคนจัดการคลังเพลง คำสั่งซื้อ และสมาชิกพร้อมกัน ตอบสนองระดับวินาทีแม้มีการเข้าชมสูง

### 🎹 วิเคราะห์ BPM และ KEY อัตโนมัติ
อัปโหลดเพลงและดึงข้อมูล **BPM, KEY, บิตเรต, แชนเนล, อัตราการสุ่มตัวอย่าง และปกอัลบั้ม** อัตโนมัติในขั้นตอนเดียว ไม่ต้องใช้เครื่องมือวิเคราะห์หลายตัว

### ☁️ พื้นที่เก็บข้อมูลบนคลาวด์และ CDN
สถาปัตยกรรมแยกส่วน: เว็บไซต์ทำงานอิสระ ไฟล์มีเดียทั้งหมดอยู่ในคลาวด์พร้อม **CDN ทั่วโลก** ไม่ต้องกังวลเรื่องแบนด์วิดท์เซิร์ฟเวอร์

### 🔒 สตรีมมิ่ง HLS หลายบิตเรต
อัปโหลดครั้งเดียวสร้างไฟล์หลายบิตเรต **320k / 256k / 192k / 128k** โดยอัตโนมัติ ใช้ **M3U8 HLS** ป้องกันการขโมยไฟล์เสียงผ่านเบราว์เซอร์

### 🛒 ระบบอีคอมเมิร์ซครบวงจร
รองรับสินค้าหลายรูปแบบ รีวิว จัดการสต็อก ติดตามการจัดส่ง หลายช่องทางการชำระเงิน ขาย **แฟลชไดร์ฟดีเจ อุปกรณ์ บัตรคอนเสิร์ต คูปอง และทรัพยากรดิจิทัล**

### 🎤 แพลตฟอร์มศิลปิน/โปรดิวเซอร์
ส่งผลงาน → ตรวจสอบ → **ระบบแบ่งรายได้ที่ปรับได้** → แดชบอร์ดรายได้ → ถอนเงิน สร้างระบบนิเวศดนตรีที่สมบูรณ์

### 💬 ชุมชนและโซเชียล
สร้างหรือเข้าร่วมกลุ่ม โพสต์อัปเดต คอมเมนต์ ถูกใจ รีโพสต์ และแชร์ สร้างการมีส่วนร่วมและการรักษาผู้ใช้

### 📢 เครื่องมือการตลาด
**Flash sales · Group buys · Pre-orders · Loyalty points · VIP tiers** — เครื่องมือส่งเสริมการขายที่หลากหลายเพื่อเพิ่มอัตราการแปลงสมาชิก

### 📺 ศูนย์รวมเนื้อหา
จัดการ **เพลง อัลบั้ม เพลย์ลิสต์ วิดีโอ อีคอมเมิร์ซ ชุมชน และผลงานศิลปิน** จากแดชบอร์ดเดียว

## 🚀 เริ่มต้นอย่างรวดเร็ว

```sh
curl -sL https://download.djaod.com/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

- แนะนำให้ผู้เริ่มต้นใช้ **BaoTa Panel** + สคริปต์ติดตั้งคลิกเดียว
- ติดตั้ง `Nginx`, `Node.js` และ `Redis` ผ่าน BaoTa Panel ก่อน แต่อย่าติดตั้ง `MongoDB` ผ่าน BaoTa Panel — ไม่สามารถกำหนดค่าคลัสเตอร์ได้ (ระบบต้องการ!)
- เมื่อสคริปต์ทำงานสำเร็จ สร้างไซต์ Node.js ใน BaoTa Panel
- สร้าง **ไซต์ฟรอนต์เอนด์** เป็น `"Default Project"` ตั้งค่า entry point เป็น `/index.js` คำสั่งเริ่มต้นเป็น `npm run index` พอร์ต `3080`
- สร้าง **ไซต์แบ็กเอนด์** เป็น `"Default Project"` ตั้งค่า entry point เป็น `/admin.js` คำสั่งเริ่มต้นเป็น `npm run admin` พอร์ต `3000`
- หมายเหตุ: BaoTa Panel เริ่มต้นไซต์โดยอัตโนมัติหลังสร้าง — หยุดก่อน แล้วใช้คำสั่งด้านล่าง
- เริ่มไซต์ฟรอนต์เอนด์:
```sh
systemctl start djaod-index.service
```
- เริ่มไซต์แบ็กเอนด์:
```sh
systemctl start djaod-admin.service
```
