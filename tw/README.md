## ✨ 核心功能

### 🚀 全新技術棧
後端採用**非阻塞非同步 IO 引擎 + 分散式資料庫**，支援高併發請求，效能遠超傳統 CMS。支援大量 DJ 站長同時線上管理曲庫、處理訂單與會員請求，高流量下仍保持秒級回應。

### 🎹 自動 BPM & KEY 分析
上傳自動精準識別 **BPM（節拍）、KEY（調性）、位元率、聲道、取樣率、音訊封面**，一鍵取代多種分析工具，大幅提升 DJ 工作效率。

### ☁️ 雲端儲存 & CDN 加速
網站與儲存完全分離，檔案託管雲端並全程 CDN 加速，秒級回應。杜絕傳統龜速上傳與播放卡頓，海量音訊也能流暢試聽。

### 🔒 多位元率 HLS 串流媒體
一鍵上傳自動產生 320k / 256k / 192k / 128k 多位元率檔案，試聽採用 **M3U8 HLS 串流播放**，杜絕瀏覽器抓包盜取音源，兼顧試聽體驗與版權保護。

### 🛒 專業商城系統
支援多屬性規格、商品評論、庫存管理、物流追蹤、多支付管道。可出售 **音樂 USB 隨身碟、DJ 裝置、門票、優惠券、雲端硬碟虛擬資源**，幫助站長快速變現。

### 🎤 音樂人平台
音樂人投稿 → 審核 → **可控分佣制度** → 收益明細 → 提現管理，打造完整音樂人生態閉環。站長靈活設定分佣比例，讓音樂人自主上傳獲取收益。

### 💬 圈子社群
建立、加入、關注圈子，釋出動態、評論點讚、轉發分享。增強使用者黏性與社交屬性，打造活躍垂直電音社群。

### 📢 多種行銷功能
**秒殺 · 團購 · 預售 · 積分 · VIP 等級** —— 豐富的促銷玩法助力會員轉換率提升與快速變現。

### 📺 多內容管理
統一管理 **音樂、專輯、歌單、影片、商城、圈子、音樂人投稿**，一站式支撐大型媒體平台。

## 🚀 快速開始

```sh
curl -sL https://download.djaod.com/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

- 建議新手使用寶塔面板 + 一鍵安裝指令碼
- 先在寶塔安裝好 `Nginx`、`Node.js` 和 `Redis`，但 `MongoDB` 不要在寶塔面板安裝，因為無法配置叢集（程式需要）！
- 等執行指令碼全部通過後，再在寶塔面板中建立 Node.js 站點
- 在 Node.js 站點管理以 `「預設專案」` 建立 **前端站點**，綁定入口為 `/index.js`，綁定命令為：`npm run index`，啟動埠為 `3080`
- 在 Node.js 站點管理以 `「預設專案」` 建立 **後端站點**，綁定入口為 `/admin.js`，綁定命令為：`npm run admin`，啟動埠為 `3000`
- 注意：在寶塔面板建立站點後預設會啟動網站，我們要先將其關閉，然後使用命令進行啟動站點
- 啟動前端站點：
```sh
systemctl start djaod-index.service
```
- 啟動後端站點：
```sh
systemctl start djaod-admin.service
```
